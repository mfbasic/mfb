#
# One libtest `--skip` substring per line: `<substring>  <why>`. The substring is
# everything up to the first run of two spaces; a `#` line or a blank line is
# ignored. Each entry must match at least one test in the landing tier's binaries,
# or test-fast.sh fails, so an entry for a renamed or deleted test cannot linger.
#
# What belongs here: a test whose cost is a sweep (every corpus fixture, every
# backend, every optimizer level, every grid cell) rather than one behavior. They
# still run in the full tier (`scripts/test-full.sh`, nightly) and on CI. A test
# that is merely slow because it re-does work every call is a speedup to make, not
# an entry. Seconds are one optimized run's `--report-time` on a loaded 12-core
# macOS host, 2026-10-17.
