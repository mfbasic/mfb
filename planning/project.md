The compiler loads project.json first, the merges/overwrites the values with project-local.json. In general project-local.json should not be put into github or other source control systems. Its ment to hold Keys, passwords, local developer settings, etc.
4) Add a new os::* functions `getConfigOr(key AS String, default AS String) AS String`, `getConfigOr(key AS String, default AS Float) AS Float`, `getConfigOr(key AS String, default AS Integer) AS Integer` that will return the config value based on the `--debug` compiler switch being present or not.
