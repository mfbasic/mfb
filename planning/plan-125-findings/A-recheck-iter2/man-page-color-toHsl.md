### 1. Saturation/lightness bounds do not say inclusive
UNIT:      man-page:color/toHsl
CLAIM:     "`hue` in degrees from `0.0` up to but not including `360.0`, `saturation` and `lightness` in `0.0`..`1.0`."
VERDICT:   incomplete
EVIDENCE:  The hue bound is spelled out as half-open, but the `saturation`/`lightness` range `0.0..1.0` is left bare right beside it, so a reader cannot tell whether `1.0` is reachable. It is: `helper_hsl.rs:__color_colorToHsl` computes `lightness = (high+low)/2` and clamps saturation with `__color_clampFraction`, and my exhaustive probe over all 256³ opaque colours (`/tmp/plan-125-scratch/A-recheck-iter2/man-page-color-toHsl/p_probe`, built with `mfb build -q .` at default `-O`) printed `sat 0.00 .. 1.00` and `lig 0.00 .. 1.00`; white gives `0.00,0.00,1.00`, black `0.00,0.00,0.00`, pure red saturation `1.00`. The sibling `mfb man color types` row says "0.0 (black) through 0.5 … to 1.0 (white)", so the function page is the only one of the two that leaves it open.
SUGGESTED: "`hue` in degrees from `0.0` up to but not including `360.0`; `saturation` and `lightness` from `0.0` to `1.0`, both ends included (`0.0` lightness is black, `1.0` is white; `1.0` saturation is a fully vivid colour)."

Everything else on the page checked true against the binary. Audit trail for the no-finding sentences: both examples compiled and ran verbatim from the page (`p_ex1` printed `120.00` / `1.00` / `0.50`; `p_ex2` printed `hue 0.00 sat 0.00` then `#808080`, matching the page's "grey reports hue 0.0, and still round-trips exactly"). The exhaustive probe found `roundtrip mismatches: 0` for `hsl(toHsl(c))` over all 16,777,216 opaque colours, confirming "`color::hsl` is the inverse"; `grey hue/sat nonzero: 0` over all 256 greys confirms the grey paragraph; max observed hue `359.76` confirms the half-open hue bound; `toHsl(rgba(255,0,0,7))` returned `0.00,1.00,0.50`, confirming alpha is ignored and not returned. The Errors table is absent and the descriptor's `errors: vec![]` agrees. No banned memory vocabulary and no compiler-internal sentences appear on the rendered page.
