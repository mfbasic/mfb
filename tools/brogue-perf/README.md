# brogue-perf

Regression and benchmark tool for bug-707: `examples/brogue`'s `dig <seed>
<depth>` (level generation) cost 150x-300x the C oracle's own user CPU time
for byte-identical output, dominated by allocation churn in two small, very
hot helper functions: `nbDx`/`nbDy` (`examples/brogue/src/grid.mfb`, plus the
sibling `cDx`/`cDy`) rebuilt an 8-element list literal on every call instead
of reading a constant, and `tileInfo` (`examples/brogue/src/level.mfb`)
materialized a whole 9-field `FloorTileType` record just so
`terrainFlags`/`terrainMechFlags` could read one field off it.

The fix (see `bugs/completed/bug-707-*.md`) hoists `nbDx`/`nbDy`/`cDx`/`cDy`'s
literals to module-level `List OF Integer` constants, and adds flat
`tileFlagsCatalog`/`tileMechFlagsCatalog` (`List OF Integer`) tables —
generated by `examples/brogue/gen/gen_tables.py` alongside the existing
record catalog — that `terrainFlags`/`terrainMechFlags` read directly instead
of calling `tileInfo`. `tileInfo`'s own signature and the other 13+ call
sites in `examples/brogue/src/terrain.mfb` are unchanged.

## What this tool checks, and how

`bench.sh` builds and runs the **real** `examples/brogue` example (via
`mfb build examples/brogue`, not a copy) and the real `oracle/` C engine
(via the same `cc` invocation `check/check-terrain.sh` uses, minus
`Architect.c`, which `check/terrain_dump.c` `#include`s directly), over a
fixed `(level seed, depth)` matrix. For each pair it takes the median of
several `/usr/bin/time`-style user-CPU-time readings (the machine this runs
on is shared and noisy — median, not single-shot, is the only reliable
number), sums the matrix, and fails if `port total / oracle total` exceeds a
budget ratio.

It also builds a `--debug` port once and reports `arena.0.alloc_calls` for
the matrix's first pair, for change-tracking across commits — this is
printed, not gated on, since the ratio is the goal the bug doc set.

This tool is a **performance** gate; it never substitutes for
`examples/brogue/check/check-terrain.sh`'s correctness check (byte-identical
output against the oracle). Run `check-terrain.sh` after any change here
shows a diff — this tool does not diff output at all.

## Usage

```
tools/brogue-perf/bench.sh [--budget N] [--runs N] [--quiet]
```

- `--budget N` — fail if the median ratio exceeds `N` (default 10, bug-707's
  proposed goal of "within 10x of the oracle").
- `--runs N` — repetitions per `(seed, depth)` pair to take the median of
  (default 5).
- `--quiet` — print only the final summary line.
- `MFB` env var — path to the `mfb` binary (default:
  `target/release/mfb` from the repository root).

Exit 0 and an `OK:` line if the ratio is within budget; exit 1 and a `FAIL:`
line otherwise.
