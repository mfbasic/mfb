# Credits

## Fonts (`resources/fonts/`)

- **Cinzel** (`Cinzel.ttf`, the variable font; its default Regular instance is
  what the demo draws) and **Cinzel Decorative Bold**
  (`CinzelDecorative-Bold.ttf`), by Natanael Gama. SIL Open Font License 1.1 —
  `resources/fonts/OFL-Cinzel.txt` and `resources/fonts/OFL-CinzelDecorative.txt`.
- **Lato** Regular, Bold and Italic (`Lato-Regular.ttf`, `Lato-Bold.ttf`,
  `Lato-Italic.ttf`), by Łukasz Dziedzic. SIL Open Font License 1.1 —
  `resources/fonts/OFL-Lato.txt`.

All four were taken from the Google Fonts repository
(<https://github.com/google/fonts>, `ofl/cinzel`, `ofl/cinzeldecorative`,
`ofl/lato`), unmodified.

## Sprites (`resources/sprites/`)

`tiles.png` and `characters.png` are the packed tile sheets
(`Tilemap/tilemap_packed.png` and `Tilemap/tilemap-characters_packed.png`) of
**Pixel Platformer** 1.2 by Kenney (<https://kenney.nl/assets/pixel-platformer>),
unmodified. License: CC0 1.0 Universal —
`resources/sprites/LICENSE-Kenney.txt`. CC0 asks for nothing; Kenney asks,
optionally, for credit, hence this entry.

## SVG artwork (`resources/svg/`)

The twelve creatures — `owl`, `fox`, `deer`, `unicorn`, `dragon`, `peacock`,
`butterfly`, `hedgehog`, `eagle`, `raccoon`, `bat` and `mushroom` `.svg` — are
from **Noto Emoji** by Google (<https://github.com/googlefonts/noto-emoji>,
`2D/svg/emoji_u1f989.svg` and siblings), renamed but otherwise unmodified.
License: Apache License 2.0 — `resources/svg/LICENSE-Noto.txt`.

`sigil.svg` was drawn for this demo and is released with this repository.

## Everything else

Every scene, the title screen, the soundtrack (synthesised at run time) and
the code were made for this demo.
